# Destigmatization Toolkit for Psychoactive Plant Medicine

Destigmatization Toolkit: a 222-source reference on psychoactive plant medicine covering pharmacology, law, and policy for six audiences. Built by RN Collins.

**Live:** https://destig-toolkit.vercel.app

## Repository contents

`404.html`, `index.html`, `robots.txt`, `sitemap.xml`, `vercel.json`, `verification.json`

## Local development

Static site. No build step — open `index.html`, or serve the directory with any static file server.

## Deployment

Deployed on Vercel from `main`. Every push to `main` triggers a production build.
